# LSPosed Shortcut

A small Android app that gives you a quick shortcut to launch LSPosed Manager or Vector.

## Features

- Opens LSPosed Manager or Vector with one tap.
- Can also be launched directly from a Quick Settings tile.
- Dynamically switches between the LSPosed and Vector launcher icons.
- Dynamically updates the Quick Settings tile name, icon, and description based on the active manager.
- Option to hide the launcher icon entirely and rely only on the Quick Settings tile.

## Requirements

- Rooted Android device.
- LSPosed Manager or Vector installed.

## Installation

You can install the app in either of the following ways:

- Download the latest APK from [Releases](https://github.com/merbah3266/LSPosed_Shortcut/releases/).
- Build the project yourself and install the APK on your Android device.

Then simply tap the app icon to open the appropriate manager.

## How do I hide the launcher icon?

Long-press the Quick Settings tile to open its settings screen, then enable the hide option.
